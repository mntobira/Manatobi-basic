## v2 アップグレードの3大進化ポイント

### 1. 全国47都道府県 公立高校入試研究データベース＆内申シミュレーター (`src/data/prefectureExams.ts`, `src/components/PrefectureExamGuide.tsx`)
- **インタラクティブ日本地図タイルセレクター**: 北海道〜沖縄県まで47都道府県を日本地図タイルから1タップで切替可能。地方・解答形式・内申対象学年・英語外部検定（英検等）優遇タイプ・キーワード（高校名・C問題・マークシート等）で瞬時にフィルタリングできます。
- **47都道府県すべてに独自の「内申点自動換算 ＆ 志望レベル別・目標当日点シミュレーター」を搭載**:
  - 東京都立の「実技4教科×2倍の65点満点→300点換算＋ESAT-J 20点加算」、神奈川県立の「中2＋中3×2の135点満点」、大阪府立の「タイプⅠ〜Ⅴ（中1:中2:中3＝1:1:3）＋英検2級80%・準1級100%みなし得点保証」、兵庫県立の「5教科×4倍＋実技4教科×7.5倍＝250点満点」、北海道の「A〜Mランク（315点満点）」、岡山・香川などの複数年変則実技傾斜まで全47都道府県の計算式を忠実実装。
  - 中1〜中3の5教科・実技4教科評定を入力すると、内申換算点・得点率と、トップ進学校／準難関校／標準校の**当日5教科目標点ライン**を自動試算します。
- **2都道府県 徹底比較モード**: 隣接県や転居・併願検討に使える横並び10項目比較テーブルを搭載。
- **2026〜2027年最新入試改革アラート**: 埼玉県2027年度（令和9年度）のマークシート全面導入・面接「マイボイス」全員実施・国語作文廃止、神奈川県2027年度共通選択型特色検査のマークシート化、千葉県リスニング1回読み＆マーク併用、山梨県英語50分化などを網羅。

## 技術構成・品質検査コマンド

```bash
npx tsx scripts/validate-juken-data.mts              # 47都道府県＆5教科279問の品質ゲート検査
npm run gen:index                                    # 軽量章インデックス (chapterIndex.generated.ts) 再生成
npm run gen:battle-pool                              # 5教科279問の対戦・マナラッシュ出題プール再生成
NODE_OPTIONS="--max-old-space-size=1536" npm run build # Vite 本番ビルド (dist/ 出力)
pm2 start ecosystem.config.cjs                       # ポート3000でプレビューサーバー起動
```
