## v6 アップデートハイライト

### 1. 教科ハブの「分野別カード分割」＆ まなとび英文法式「5問ステージ＋難易度フィルタ」UI
- **1カード一括表示を廃止し、分野ごとに独立した2×2グリッドカードへ分割 (`StudyCatalog.tsx` / `studyCatalog.ts`)**:
  - **理科（4分野）**: **生物分野**（植物・人体・遺伝・生態系）／ **物理分野**（光・音・力・電流磁界・運動エネルギー）／ **化学分野**（気体・水溶液・化学変化・イオン中和電池）／ **地学分野**（火山地震地層・天気湿度・天体）
  - **社会（3分野）**: **地理分野** ／ **歴史分野** ／ **公民分野**
  - **数学（4分野）**: **数と式・方程式** ／ **関数・グラフ融合** ／ **平面・空間図形** ／ **確率・箱ひげ図**
  - **国語（4分野）**: **漢字・語彙・慣用句** ／ **口語文法・敬語** ／ **古文・漢文・韻文** ／ **現代文読解**
  - **英語（4分野）**: **中1・中2重要文法** ／ **中3最重要文法** ／ **語順整序・対話完成** ／ **長文・グラフ読解**
- **難易度フィルタ＆5問小刻みステージ制 (`ChapterSelection.tsx`)**:
  - 単元選択画面上部に **「すべて ／ ★基礎 ／ ★★標準 ／ ★★★実戦」** の難易度ピルフィルタを新設。
  - 全5教科を「まなとび英文法」と同じ **1ステージ4〜6問（約2〜3分）の小刻みクリア方式** に統一し、スマホのスキマ時間でテンポよく完走できる設計を実現。

### 2. 社会：「第6問B式」左右矢印スライド資料カルーセル ＆ 記述問題の4択選択化
- **複数資料スライド切替 (`JukenMaterialCarousel.tsx`)**:
  - マナトビリスニング第6問Bの図表切替UIをベースに、左右の矢印ボタン（`‹` ／ `›`・44px親指タップ対応）・横スワイプ・下部ピルタブ（`資料1` / `資料2` / `資料3`）で雨温図・統計表・年表・仕組み図を省スクロールで切り替え可能。
  - 表のセルはタップで `○ → × → 空欄` の仮メモを付けながら消去法で解くことができます。
- **スマホ入力ストレスゼロの「全問4択（記述文選択式）」化**:
  - 社会科の従来の文字入力問題（全20問）を含む **全223問すべてを4択化**。因果関係の説明記述も「正しい理由説明文を4択から選ぶ」実戦記述選択形式に統一しました。

### 3. 数学：グラフ・図形の前面表示 ＆ 解説での「✏️ 書き込み解説図 / 元の図」ワンタップ比較
- **問題画面での図版最優先レイアウト (`ProblemPane.tsx` / `AnswerPane.tsx`)**:
  - 関数グラフ・平面図形・空間図形をリード文より上の最上段に大きく配置し、スマホ1画面で図と選択肢を見比べられる省スクロール設計。
- **解説での補助線・底辺・高さ・切断面の書き込み図切替 (`MathAnnotatedFigureToggle.tsx`)**:
  - 解説画面では **「✏️ 書き込みON」** が初期表示され、放物線と直線の等積変形・原点分割、円と接線の直角三角形・相似補助線、立方体切断の正三角形断面と三角錐の高さ、円錐展開図の側面中心角、箱ひげ図の四分位範囲などを赤・青の色分け補助線つきSVGで視覚化。ワンタップで **「元の図」** と比較できます（計11組の専用SVGペアを収録）。

## 検証・生成・ビルドコマンド

```bash
npm run gen:index                                      # 軽量章・分野インデックス (chapterIndex.generated.ts) 再生成
npm run gen:battle-pool                                # 5教科1,095問の対戦・マナラッシュ出題プール再生成
npx tsx scripts/validate-juken-data.mts                # 47都道府県＆5教科52単元1,159問（重複0件・図版実在・社会4択）品質検査
python3 scripts/generate-v6-svgs.py                    # 数学「問題図＋書き込み解説図」＆社会スライド資料SVG一括生成
pm2 stop all && NODE_OPTIONS="--max-old-space-size=1536" npx vite build  # 本番Viteビルド (dist/)
pm2 restart mntb-juken                                 # ポート3000でプレビューサーバー再起動
```
