## v7.0 アルティメット品質強化ハイライト

### 1. 社会 全11単元（100%）に「第6問B式」左右矢印スライド資料カルーセルを完全配備（計14組）
- マナトビリスニング第6問B直系の **`JukenMaterialCarousel`**（左右矢印 `‹` / `›`・横スワイプ・`資料1 / 資料2 / 資料3` ピルタブ・表セルの `○/×` タップメモ・**`🔍 拡大` フルスクリーンモーダル**）を、地理・歴史・公民の **全11単元すべて（カバレッジ100%・計14組42スライド）** に配備しました。
- スマホでの文字入力負荷をゼロにするため、社会の **全273問すべてを4択（因果・理由の記述文選択を含む）** に統一しました。

### 2. 数学・理科の「問題図 ⇔ ✏️ 書き込み解説図」29件 ＋ 🔍フルスクリーン比較モーダル搭載
- 問題画面では関数グラフ・平面/空間図形・実験装置・人体循環・地層柱状図を最上段に大きく表示。
- 解説画面では **`MathAnnotatedFigureToggle`** により、初期状態で **補助線・高さ・底辺・等積変形・0またぎ変域・3重相似・累積相対度数・光路作図・BTB対照実験・心臓血液循環・気体3捕集法・ダニエル電池電子移動・柱状図標高対比** を色分け書き込みした解説図（`✏️ 書き込みON`）を表示し、ワンタップで **「元の図」** と切替比較できます。
- さらに **`🔍 拡大` ボタン**からフルスクリーンモーダルを開き、画面いっぱいに拡大した状態でも `✏️ 書き込みON ⇔ 元の図` を切り替えられます（画像本体のタップ暴発ゼロ設計）。

### 3. 単元ステージ選択の「視覚特徴バッジ」＆ 難易度フィルタ
- 単元選択画面のステージ行に **`✏️書き込み図解`**・**`📊スライド資料`**・**`📐図表`** のカラーピルバッジを自動表示し、図解・資料読解ステージが一目で選べるようになりました。
- 上部の **「すべて ／ ★基礎 ／ ★★標準 ／ ★★★実戦」** フィルタと5問小刻みステージ制で隙間時間にテンポよく完走できます。

### 4. 全4択問題（1,233問すべて）に「具体的な誤答理由解説」100%完備（短文解説ゼロ保証）
- 1,233問すべての誤答選択肢に対し、単なる「誤り」「計算ミス」のような短文を完全排除（16文字未満の短文誤答解説 **0件** を `validate-juken-data.mts` で常時検査）し、「どの公式・符号・歴史事項と混同したか」がその場でわかる教育的解説を徹底しました。

## 検証・生成・ビルドコマンド

```bash
npm run gen:index                                      # 軽量章・分野インデックス (chapterIndex.generated.ts) 再生成
npm run gen:battle-pool                                # 5教科1,235問の対戦・マナラッシュ出題プール再生成
npx tsx scripts/validate-juken-data.mts                # 47都道府県＆5教科52単元1,299問（重複0件・短文解説0件・全社会単元スライド資料・図版実在）検査
python3 scripts/generate-v6-svgs.py                    # v6 数学・社会SVG生成
python3 scripts/generate-v65-svgs.py                   # v6.5 理科・数学・社会SVG生成
python3 scripts/generate-v7-svgs.py                    # v7 数学・理科・社会SVG（22枚）生成
pm2 stop all && GOMAXPROCS=2 UV_THREADPOOL_SIZE=2 NODE_OPTIONS="--max-old-space-size=1200" npx vite build
pm2 restart mntb-juken                                 # ポート3000でプレビューサーバー再起動
```
