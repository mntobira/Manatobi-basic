## 🛠 技術構成・コマンド

- **Frontend**: React 19 + TypeScript 5.8 + Vite 6 + Tailwind CSS v4 + Motion + KaTeX + Lucide Icons + Firebase Auth/Firestore（オフライン端末保存フォールバック完備）
- **Edge Preview Runtime**: Cloudflare Pages (`wrangler pages dev dist`) + PM2

```bash
npm run gen:index        # 5教科の軽量章インデックス (chapterIndex.generated.ts) を再生成
npm run gen:battle-pool  # 5教科の対戦・マナラッシュ出題プールを再生成
npm run build            # Vite 本番ビルド (dist/ 出力)
pm2 start ecosystem.config.cjs # ポート3000でプレビューサーバー起動
```
