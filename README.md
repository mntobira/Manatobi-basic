## 検証・生成・ビルドコマンド

```bash
npx tsx scripts/validate-juken-data.mts                # 47都道府県＆5教科52単元1,034問（重複0件）の品質ゲート検査
npx tsx scripts/dump-juken-pdf-payload.mts             # PDF生成用ペイロード書き出し
python3 scripts/build-juken-gacha-prints.py            # 全76冊PDF・高視認性WebPサムネイル・ぼかしプレビュー生成
npm run gen:index                                      # 軽量章インデックス (chapterIndex.generated.ts) 再生成
npm run gen:battle-pool                                # 5教科953問の対戦・マナラッシュ出題プール再生成
pm2 stop all && NODE_OPTIONS="--max-old-space-size=900" npm run build  # 省メモリ本番Viteビルド (dist/)
pm2 start ecosystem.config.cjs                         # ポート3000でプレビューサーバー起動
```
