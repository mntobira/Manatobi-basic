## v3 品質向上（Quality Elevation）の4大進化ポイント

### 1. 3本柱の学習導線解放（実戦演習 ⇄ スピード小テスト ⇄ 赤シート要点まとめ）
- **`ModeSelection.tsx`・`StudyCatalog.ts`・`ChapterSelection.tsx` 連携強化**:
  - これまで内部データのみ存在していた全35単元の専用「**スピード小テスト（`mini_test`）**」を学習モード選択画面・演習カタログ・単元一覧の切替ピル（`実戦演習 ⇄ 小テスト`）すべてから1タップで起動できるよう完全開放。
  - 全35単元のすべてに**最低3問以上のスピード小テスト（計105問）**を整備し、本番形式の**入試実戦演習（計244問）**と重複ゼロで段階学習が可能。

### 2. 中学生が「なぜ間違えたか」をひと目で理解できる答え合わせ・解説UI刷新 (`Explanation*`, `SubQuestionCard.tsx`)
- 回答画面と同じ温かいクリーム紙地（`#fcf5e9`）・教科別テーマカラー・立体3D進行ボタン（`つぎの問題へ` ／ ゴールドの `結果サマリーを見る！`）へ全面統一。
- **重複テキストの排除＆構造化「ひっかけ選択肢カード」**:
  - 解説冒頭の冗長な `【正解】` 再掲を自動整形し、`ア・イ・ウ・エ` バッジ付きの「あなたの解答 vs 正解」比較カードを明快に表示。
  - 誤答選択肢の根拠（`distractors`）を専用カード化し、**学習者が実際に選んでしまった誤答選択肢をローズ色でハイライト（`あなたが選んだ選択肢` バッジ付き）**して消去法の根拠と「答えの核心・正解までの3ステップ」を直感的に提示。
