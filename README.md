## 検証・生成・ビルドコマンド

```bash
npm run gen:index                                      # 軽量章・分野インデックス (chapterIndex.generated.ts) 再生成
npm run gen:battle-pool                                # 5教科1,290問の対戦・マナラッシュ出題プール再生成
npx tsx scripts/validate-juken-data.mts                # 47都道府県＆5教科52単元1,354問（重複0件・短文解説0件・数理全24章図解・社全11章スライド検査）
python3 scripts/generate-v6-svgs.py                    # v6 数学・社会SVG生成
python3 scripts/generate-v65-svgs.py                   # v6.5 理科・数学・社会SVG生成
python3 scripts/generate-v7-svgs.py                    # v7 数学・理科・社会SVG（22枚）生成
python3 scripts/generate-v8-svgs.py                    # v8 数・理全章コンプリート＆英・国スライド用SVG（18枚）生成
pm2 stop all && VITE_FAST_BUILD=true node --max-old-space-size=680 ./node_modules/vite/bin/vite.js build
pm2 restart mntb-juken                                 # ポート3000でプレビューサーバー再起動
```
